# Hey Kay · דף הרשמה לפיילוט

דף סטטי אחד (`index.html`) עם תהליך הרשמה קצר, שאלה אחת בכל מסך, שבסופו נפתח וואטסאפ עם הודעה מוכנה למספר של Hey Kay.
אין שרת, אין מסד נתונים, אין analytics ואין cookies. הבקשה החיצונית היחידה היא לגופן Rubik מ־Google Fonts.

כתובת חיה: https://yossidisk.github.io/HeyKay/
(הכתובת הישנה של התצוגה המקדימה, `/v2/`, מפנה לדף הראשי.)

## התהליך
1. דף נחיתה עם כפתור אחד: "בואו נבנה לך תוכנית סרטונים".
2. שמונה שאלות, אחת בכל מסך: שם, שם העסק, מה העסק עושה, קהל, מטרות (בחירה מרובה), סגנון מול המצלמה, כמה סרטונים בשבוע (אופציונלי), טיקטוק / אינסטגרם / אתר (אופציונלי).
3. מסך "בונים לך תוכנית", ואז תוכנית אישית, אישור תנאים ושליחה בוואטסאפ.
4. מסך הצלחה עם קוד HK.

ה־progress bar מתחיל ב־12% ורץ מהר בהתחלה ולאט לקראת הסוף. האחוזים לכל שלב מוגדרים במערך `STEPS` ב־`index.html`.

## איך משנים את המספר
בראש ה־`<script>` ב־`index.html`:
```js
const CONFIG = {
  WA_NUMBER: "972552948188", // קידומת מדינה, בלי + ובלי 0 מוביל. לדוגמה 0501234567 → "972501234567"
  PILOT_OPEN: true,
};
```

## איך סוגרים את הפיילוט
משנים ל־`PILOT_OPEN: false`. במקום הכפתור יופיע "הפיילוט מלא כרגע 🙏".

## העלאה
**GitHub Pages** (כבר מוגדר בריפו הזה): כל push ל־`main` מתפרסם אוטומטית תוך דקה–שתיים.
כדי להגדיר מחדש: Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `(root)`.

**Netlify**: [app.netlify.com/drop](https://app.netlify.com/drop) וגוררים את התיקייה, או מחברים את הריפו (בלי build command, publish directory = `/`).

## פורמט ההודעה (הבוט מפרסר לפי התוויות, לא לשנות אותן)
```
היי Kay! נרשמתי לפיילוט 🙌
קוד: HK-4821
שם: דנה
שם העסק: סטודיו דנה
עסק: סטודיו לפילאטיס בחולון
קהל: נשים 30–50 באזור
אתר: studio-dana.co.il
מטרה: יותר לקוחות חדשים, חשיפה למותג
מול מצלמה: רק קול
סרטונים בשבוע: 3–4
טיקטוק: @dana.pilates
אינסטגרם: @dana.pilates
✅ אישרתי את תנאי הפיילוט
```
- שורות אופציונליות (אתר, סרטונים בשבוע, טיקטוק, אינסטגרם) נכנסות רק אם מולאו.
- "מטרה:" יכולה להכיל כמה ערכים, מופרדים ב־", ".
- "דמות ציבורית:" ו"מייחד:" כבר לא נשלחות (הוסרו בגרסה 2).
- קוד HK נשמר ב־sessionStorage, כך ששליחה חוזרת באותו טאב שומרת על אותו קוד.
